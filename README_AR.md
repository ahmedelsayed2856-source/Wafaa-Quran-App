# القرآن الكريم — صدقة جارية على روح وفاء عاشور الزهار

## الوظائف
- مصحف بالرسم العثماني متاح دون إنترنت **بعد بناء APK**؛ يجلب سكربت البناء النص من AlQuran Cloud ويضمن وجود 114 سورة و6236 آية، ويتوقف البناء إذا كان المصدر ناقصًا.
- مكتبة قراء MP3Quran (تحتاج الإنترنت لتحديث القائمة).
- تشغيل التلاوات مباشرة أو تنزيل السورة داخل التطبيق؛ تشغيل السور المحفوظة دون إنترنت، مع زر حذفها.
- التنزيلات محفوظة في مساحة التطبيق الخاصة؛ حذف التطبيق يحذفها.

## بناء APK مجانًا عبر GitHub
1. أنشئ مستودعًا جديدًا وارفع **محتويات هذا المجلد android** إلى جذر المستودع (بما فيها مجلد `.github` المخفي).
2. من Actions اختر `Build Wafaa Quran APK` ثم `Run workflow`.
3. بعد نجاح البناء افتح آخر تشغيل، ثم قسم Artifacts، ونزّل `Wafaa-Ashour-AlZahhar-Quran-APK`.
4. فك ZIP وستجد `app-debug.apk` لتثبيته أو إرساله. هذا APK تجريبي موقّع بمفتاح Debug وليس نسخة متجر نهائية.

## ملاحظات مهمة
- يتطلب البناء الأول اتصال إنترنت على GitHub للحصول على حزم أندرويد ونص القرآن.
- راجع رسم المصحف ومطابقته للمصحف المعتمد قبل النشر الواسع.
- التلاوات تخضع لحقوق وإتاحة MP3Quran؛ تحقق من شروط إعادة التوزيع والتخزين قبل النشر العام.
- قد تتطلب بعض التسجيلات اتصالًا بالإنترنت أو تكون غير متاحة؛ تنزيل جميع المقرئين دفعة واحدة غير مدعوم.
- هذا مشروع مصدر جاهز للبناء، **وليس ملف APK مبنيًا**.
